# Frontend

พื้นที่สำหรับ Mobile-first PWA ที่เผยแพร่ผ่าน GitHub Pages

โครงสร้างที่วางไว้:

```text
frontend/
├── index.html
├── manifest.webmanifest
├── service-worker.js
├── assets/
├── src/
│   ├── api/
│   ├── components/
│   ├── pages/
│   ├── storage/
│   ├── styles/
│   └── utils/
└── tests/
```

เริ่ม implementation ใน Phase 4 หลัง API/OCR contract ผ่าน integration test.
