# Dashboard analytics — PALM LEDGER

## สถานะ

ฟีเจอร์ analytics รุ่น `2.7.0` และการส่งออก CSV/PDF รุ่น `2.7.1` เผยแพร่และตรวจแล้ว ใช้ `dashboard.summary` API เดิมของ Apps Script `1.3.1` จึงไม่ต้องเผยแพร่ Code.gs เพิ่ม

## ข้อมูลที่แสดง

แดชบอร์ดอ่านเฉพาะรายการขายที่บันทึกแล้วและไม่ถูกยกเลิกจาก Google Sheets ไม่รวม OCR ที่อ่านสำเร็จแต่ยังไม่ได้กดยืนยันบันทึก

| ตัวชี้วัด | ความหมาย |
|---|---|
| รายรับจากใบชั่ง | ผลรวม `NetAmount` ของรายการขาย หลังรายการหักในใบชั่งและก่อนหักค่าแรง |
| ราคาเฉลี่ยต่อกิโลกรัม | ค่าเฉลี่ยถ่วงน้ำหนักตามน้ำหนักขายที่ใช้ได้ (`PayableWeightKg`) ไม่ใช่ค่าเฉลี่ยธรรมดาของราคาแต่ละบิล |
| ผลผลิต | ผลรวมน้ำหนักขายที่ใช้ได้ในช่วงนั้น |
| ค่าแรง | ผลรวมค่าแรงของรายการที่ยัง active |
| คงเหลือหลังค่าแรง | รายรับจากใบชั่งลบค่าแรงที่บันทึกไว้ ตัวเลขนี้ยังไม่ใช่กำไรสุทธิของสวน เพราะยังไม่รวมปุ๋ย ขนส่ง น้ำมัน เครื่องมือ หรือค่าใช้จ่ายอื่นที่ยังไม่ได้บันทึก |

## สิ่งที่เพิ่มใน production 2.7.0

- เลือกกราฟรายเดือนระหว่างรายรับ ราคาเฉลี่ย/กก. และผลผลิต
- สรุปเดือนที่รายรับ ราคาเฉลี่ย และผลผลิตสูงสุด พร้อมเปรียบเทียบราคาเดือนล่าสุดกับเดือนก่อนหน้าที่มีบิล เมื่อเลือกปีเดียว
- ตารางรายเดือนแสดงจำนวนใบชั่ง น้ำหนัก รายรับ ราคาเฉลี่ย ค่าแรง และคงเหลือหลังค่าแรง พร้อมยอดรวมช่วงที่เลือก
- แสดงราคาเฉลี่ยของแต่ละลานรับซื้อในรายการเปรียบเทียบ
- เลือกปีปัจจุบันเป็นค่าเริ่มต้นเพื่อให้กราฟเรียงตามเวลา ส่วน “ทุกปี” รวมเดือนชื่อเดียวกันจากหลายปีเพื่อดูฤดูกาล ไม่ควรอ่านเป็นแนวโน้มเดือนต่อเดือน

## การส่งออกรายเดือนใน production 2.7.1

- ปุ่ม CSV ดาวน์โหลดตารางรายเดือนตามปีที่เลือกหรือมุมมองทุกปี เป็น CSV UTF-8 พร้อม BOM เพื่อให้ข้อความภาษาไทยอ่านได้ใน spreadsheet ทั่วไป
- ไฟล์มีเดือนทั้ง 12 เดือน จำนวนใบชั่ง ผลผลิต ยอดรับจากใบชั่ง ราคาเฉลี่ยถ่วงน้ำหนัก ค่าแรง และคงเหลือหลังค่าแรง พร้อมแถวรวม; เดือนที่ไม่มีบิลเว้นค่าตัวเลขว่าง
- ปุ่ม PDF เปิดกล่องพิมพ์ของเบราว์เซอร์ด้วยหน้ารายงาน A4 แนวนอน ผู้ใช้เลือก “บันทึกเป็น PDF” จากปลายทางการพิมพ์ของอุปกรณ์
- รายงานแสดงปี/ช่วงเวลาที่เลือกและหมายเหตุเรื่องการรวม “ทุกปี”; ไม่รวมชื่อผู้ซื้อหรือข้อมูลส่วนบุคคล และไม่บันทึกข้อมูลเพิ่มใน backend
- คงนิยามตัวเลขเดิม: ยอดรับเป็นยอดก่อนหักค่าแรง และคงเหลือหลังค่าแรงยังไม่ใช่กำไรสุทธิ

## แนวทางต่อยอดจากข้อมูลที่มี

1. **กำไรจริงและต้นทุนต่อกิโลกรัม** — เพิ่มบันทึกค่าใช้จ่ายสวนที่จัดหมวดหมู่ได้ เช่น ปุ๋ย น้ำมัน ขนส่ง และซ่อมบำรุง ก่อนแสดงกำไรหรือ margin; ตอนนี้ข้อมูลไม่พอจะเรียกเงินหลังหักค่าแรงว่า “กำไรสุทธิ”
2. **ผลผลิตตามพื้นที่/แปลง** — เพิ่มรหัสแปลงและพื้นที่ (ไร่) เพื่อคำนวณกิโลกรัมต่อไร่และเปรียบเทียบแปลง โดยไม่ต้องอนุมานจากยอดรวมสวน
3. **จังหวะราคาและการขาย** — เมื่อมีข้อมูลหลายเดือนต่อเนื่อง ให้ติดตามราคาเฉลี่ยเทียบเดือนก่อนหน้า/ปีก่อน และดูความสัมพันธ์ระหว่างราคา ปริมาณ และลานรับซื้อ
4. **แผนเงินสดค่าแรง** — แสดงค่าแรงค้างจ่ายและแนวโน้มยอดที่ต้องจ่ายจากรายการ active เพื่อช่วยวางแผนกระแสเงินสด

การคำนวณทั้งหมดควรแยก “ข้อมูลที่บันทึกจริง” ออกจาก “ข้อเสนอแนะ” และไม่สร้างราคาอ้างอิงตลาดหรือกำไรจากข้อมูลที่ไม่มีในชีต
