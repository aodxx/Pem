# การวิเคราะห์ใบชั่งตัวอย่าง

อัปเดตล่าสุด: 2026-08-12  
Phase: 0 — Discovery & Architecture

## ข้อสรุป

ภาพตัวอย่างทั้งสองใบยืนยันว่าเอกสารมีโครงสร้างหลักเหมือนกัน แต่คุณภาพภาพแตกต่างมาก ระบบจึงต้องแยก 3 ขั้นตอนออกจากกันอย่างชัดเจน:

1. ตรวจคุณภาพและปรับแนวภาพ
2. ให้ Gemini อ่านข้อมูลเป็น Structured JSON โดยห้ามเดาค่าที่มองไม่ชัด
3. ตรวจความสัมพันธ์ทางคณิตศาสตร์และให้ผู้ใช้ยืนยันก่อนบันทึก

ค่าที่ไม่สามารถอ่านได้ต้องเป็น `null` พร้อม confidence ต่ำ ห้ามแทนด้วย 0 ยกเว้นรายการหักที่เอกสารระบุชัดว่าไม่มีหรือเป็น 0

## Field ที่พบในเอกสารและควรรองรับ

| กลุ่ม | Field มาตรฐาน | ตัวอย่างข้อความบนใบชั่ง |
|---|---|---|
| เอกสาร | receiptNumber | เลขที่ |
| คู่ค้า | buyerName, branch, address, phones | ชื่อร้าน/ลาน, สาขา, ที่อยู่ |
| ลูกค้า | customerCode, customerName | ทะเบียนรถ/ลูกค้า |
| ผลผลิต | productCode, productName | 000 - ทะลาย / ปาล์มทะลาย |
| เวลา | saleDate, timeIn, timeOut | รถเข้า, รถออก |
| น้ำหนัก | grossWeightKg | น้ำหนักเข้า |
| น้ำหนัก | tareWeightKg | น้ำหนักออก |
| น้ำหนัก | netWeightKg | น้ำหนักสุทธิ |
| น้ำหนัก | deductionWeightKg | ยอดหักน้ำหนัก |
| น้ำหนัก | payableWeightKg | นน.คงเหลือ / น้ำหนักคิดเงิน |
| ราคา | pricePerKg | ราคา |
| เงิน | grossAmount | เป็นเงิน |
| เงิน | totalDeduction | ยอดหักเงิน |
| เงิน | netAmount | คงเหลือ |
| คน/หลักฐาน | operatorName, signaturePresent | พนักงานชั่ง, ลายเซ็น |
| คุณภาพ | handwrittenNotes, stampPresent | ลายมือ/ตราประทับ |

## กฎ Validation จากเอกสารจริง

- `grossWeightKg - tareWeightKg ≈ netWeightKg`
- `netWeightKg - deductionWeightKg ≈ payableWeightKg`
- `payableWeightKg × pricePerKg ≈ grossAmount`
- `grossAmount - totalDeduction ≈ netAmount`
- ค่า tolerance เริ่มต้น:
  - น้ำหนัก: ±1 กก.
  - เงิน: ±1 บาท
- หากต่างเกิน tolerance ให้แสดง Warning แต่ยังอนุญาตให้ผู้ใช้ยืนยัน
- วันเวลารถออกต้องไม่น้อยกว่าวันเวลารถเข้า
- ถ้า OCR อ่านตัวเลขที่มีความมั่นใจต่ำกว่า 0.75 ให้ไฮไลต์
- ถ้าต่ำกว่า 0.50 ให้ค่าเป็น `null` หรือบังคับตรวจด้วยตนเอง

## ข้อกำหนดการถ่ายภาพที่ UI ควรช่วยผู้ใช้

- แสดงกรอบนำทางให้วางใบชั่งเต็มกรอบ
- เตือนเมื่อภาพมืด เบลอ หรือขอบเอกสารถูกตัด
- รองรับหมุน 90 องศาและปรับมุม
- สร้างภาพสำหรับ AI ที่ปรับ orientation/contrast แล้ว แต่เก็บไฟล์ต้นฉบับไว้ด้วย
- Preview ภาพก่อนส่ง
- จำกัดขนาดไฟล์และบีบอัดสำเนาสำหรับ AI โดยไม่เขียนทับต้นฉบับ
