# Apps Script Backend

พื้นที่สำหรับ Google Apps Script Web App backend

โครงสร้างที่วางไว้:

```text
apps-script/
├── appsscript.json
├── Main.gs
├── Router.gs
├── Auth.gs
├── Config.gs
├── Errors.gs
├── Repositories.gs
├── SaleService.gs
├── DuplicateService.gs
├── GeminiService.gs
├── DriveService.gs
├── DashboardService.gs
├── Validators.gs
├── Setup.gs
└── Tests.gs
```

Secret และ resource IDs ต้องอยู่ใน Script Properties ไม่ commit ลง GitHub.
